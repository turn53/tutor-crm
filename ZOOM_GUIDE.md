# Уроки Zoom и CRM

## Перед уроком

1. Открой CRM и убедись, что Ollama работает на компьютере.
2. Используй конференцию, ID которой записан в карточке ученика или группы. Для группы нужна одна общая конференция и один отчёт.
3. Начни облачную запись вручную. Разрешённая в настройках запись сама по себе не означает, что запись началась.
4. Убедись, что запущена сводка Zoom AI. В тестовой конференции она запускается автоматически и отправляется только организатору.

## В конце урока

Полезно вслух подвести итоги: «Тема — …; ученик самостоятельно сделал …; затруднения — …; домашнее задание — …; следующий урок — …».

Заверши конференцию для всех. Zoom отдельно обрабатывает видео и сводку, поэтому отчёт появляется не мгновенно.

## После урока

Если включена автопроверка, CRM проверяет Zoom каждые 5 минут, пока сервер CRM работает. Компьютер не должен спать. Для разовой проверки: **Настройки → Подключение Zoom → Проверить сейчас**, затем **Обновить статус**.

Результат появится в **Занятиях**. Проверь домашку, формулы и названия: ошибки распознавания Zoom могут перейти в отчёт. Если сведений нет в сводке, модель не должна их придумывать. Конспект можно просмотреть и скачать для самостоятельной отправки ученику. Автоматической рассылки нет.

## Условия импорта

- В Zoom должны быть готовы облачная запись и сводка.
- В статистике конференции должно быть не менее двух участников. Для теста можно подключить телефон с выключенными микрофоном и динамиком.
- ID конференции должен быть однозначно привязан к одной карточке ученика или группы.
- Проверяются записи за последние 7 дней. Один сеанс не импортируется повторно; удалённый через корзину отчёт сам не восстанавливается.
- Видео хранится в Zoom. В CRM сохраняются отчёт, исходная сводка и ссылка на запись. После удаления видео из Zoom ссылка не заменяет архивную копию.
- Для локального разбора нужна модель Ollama и свободная оперативная память. Не закрывай Ollama во время обработки.
- В текущем режиме сводки длиннее 9000 символов требуют ручной обработки: текст не обрезается молча.
- Изменение текста в Zoom после импорта не перезаписывает отчёт CRM.

Ключи подключения хранятся локально в `zoom.local.json`; не передавай этот файл вместе с проектом.
