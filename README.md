# Класс — CRM репетитора

Первая локальная версия на Python 3.11+ и SQLite. Без внешних Python-зависимостей и платных модулей. Собственная реализация, не форк EspoCRM.

Локальный запуск: `python app.py`, затем http://127.0.0.1:8765. Компьютер должен работать. По умолчанию сервер слушает только loopback. Для публичной установки используются Compose и Caddy по DEPLOYMENT.md; Python-порт отдельно в интернет не публикуется.

## Готово
- Ученики (включая завершивших): контакты родителей, класс, цель, фильтры по статусу, группе и классу.
- Условия индивидуальных занятий — в карточке ученика; состав группы, общая цена часа на участника и индивидуальные цены — в карточке группы.
- Условия включают цену часа, месячный бюджет и предполагаемое окончание. Завершение условий сохраняет историю.
- Единый раздел «Финансы»: согласованная сумма за месяц, частичные оплаты и возвраты, остаток и переплата. При добавлении суммы предлагается месячный бюджет из условий; его нужно подтвердить.
- Общий отчёт на урок группы, домашка, внутренние замечания, следующий шаг, текст конспекта и ссылка на запись.
- Фильтры занятий по ученику, группе и датам. Конспект можно предварительно просмотреть и скачать без внутренних замечаний для отправки вручную.
- Удаление в корзину и восстановление в «Настройках». Удаление ученика или группы сохраняет прошлые финансовые операции; удаление ошибочной оплаты, суммы к оплате или занятия пересчитывает соответствующие показатели.
- Экспорт JSON; данные сохраняются в `crm.sqlite3`. Для полной резервной копии остановите сервер и скопируйте базу.

## Определения
Поступления: сумма переводов минус возвраты. Это кассовая сумма, не прибыль.
Прогноз: сумма месячных бюджетов активных форматов со следующего месяца до месяца окончания включительно. Предоплаты не вычитаются; прогноз показывает стоимость обучения, а не оставшийся денежный поток.
Средняя цена часа ученика: сумма стоимости уроков по снимкам тарифов / его часы. Групповой урок считается один раз в часах преподавателя. Выручка за час преподавателя суммирует всех участников.
Начисления вводятся отдельно и не меняются вслед за тарифами. Один платёж за разные месяцы разбивается на отдельные записи. Посещение отдельных участников и пропуски пока не учитываются: стоимость группы включает участников активных тарифов на момент добавления урока.

## Ограничения первой версии

Этот раздел сохранён как описание ранней локальной версии. Он не описывает текущий VPS: публичный HTTPS-доступ, автоматические интеграции и локальная модель на сервере уже развёрнуты.
Zoom API подключён; запись и сводка тестового звонка получены. Установлена Ollama с моделью qwen2.5:1.5b. Нет внешнего доступа, кабинета ученика и импорта реальной базы. Дата, участники и длительность проведённого урока после создания заблокированы для сохранения финансовой истории; текст отчёта редактируется. Состав/цены задним числом берутся из активных условий на момент добавления урока, поэтому исторический импорт пока не поддерживается.

## Подключение Zoom
Нужна Server-to-Server OAuth интеграция в аккаунте владельца. Права чтения: `cloud_recording:read:list_user_recordings:admin`, `meeting:read:past_meeting:admin`, `meeting:read:summary:admin`. Официальный API: https://developers.zoom.us/docs/api/meetings/ . В разделе «Настройки → Подключение Zoom» ввести Account ID, Client ID, Client Secret и email владельца. Они сохраняются в `zoom.local.json` (не зашифрован, защищён доступом к Windows-профилю; не включать в резервные копии для передачи другим людям). В карточке ученика или группы указать ID постоянной конференции. Дублирующиеся привязки пропускаются. Включить автопроверку или нажать «Проверить сейчас».

Проверка каждые 5 минут, окно последних 7 дней. Требуются готовая запись, сводка и как минимум два участника по статистике Zoom. Ключ уникальности — UUID сеанса. Перезапуск конференции создаёт новый UUID; объединение частей урока после переподключения пока не поддерживается. Нужен пилот до боевого использования.

Для автоматического разложения сводки по полям установить Ollama, загрузить подходящую русскоязычную модель и указать её имя в настройках. Модель вызывается только на `127.0.0.1:11434`, платных ИИ API нет. Без модели сохраняется исходная сводка во внутреннем поле, домашка и конспект автоматически не формируются. Сгенерированный конспект — черновик, его нужно проверить перед отправкой. Видео остаётся в Zoom, в CRM хранится ссылка. Исходная сводка не включается в ученический текстовый экспорт. Изменения сводки после первого успешного импорта автоматически не перезаписывают ручной отчёт.

Тесты: `python -m unittest -v`.

Пошаговая памятка: [ZOOM_GUIDE.md](ZOOM_GUIDE.md). Для экономии памяти модель выгружается после обработки. Сводки длиннее 9000 символов требуют ручной обработки и не обрезаются автоматически.
